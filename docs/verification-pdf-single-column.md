# 单栏文字型 PDF 结构解析验证

2026-10-23。单栏、有文字层普通 PDF 的结构解析、完整图、媒体顺序、结构化表格、跨页续表和引用展示均已实现；双栏与扫描件仍在范围外。

## 真实样本对照

用户提供 20 页、有文字层、单栏的架构规范 PDF，包含 6 张内嵌栅格图；文档没有书签。对照渲染后的第 1–3 页，并检查全文解析结果。

| 项目 | 修改前 | 修改后 |
| --- | --- | --- |
| 标题 | 无标题类型，每页合成一个大段落 | 20 个一级标题、74 个二级标题，正文携带章节路径 |
| 页边内容 | 页眉、页脚及页码进入正文，页脚还会排在正文前 | 根据跨页重复及边缘位置清理 |
| 段内换行 | 中文词和 `Ingress` 等标识符被割裂 | 恢复自然段及中英混合标识符，元信息行分别保留 |
| 图注 | 6 张图片的图注均为空 | 6 张全部绑定；已绑定图注不进入普通正文 |
| 位置 | 只有页码，无区域 | 全部内容块带物理页和左上角 point 坐标 |

正式受限工作进程输出：20 页、94 个标题、304 个非空内容块，另保留 6 个移除图注后的空单位以兼容现有处理流程；6 张图片均有图注。坐标保存在切片现有 JSON 结构中，不新增重复正文表。

## 实现与兼容

- PDF 先统计正文／标题字号及重复边缘行，再逐页恢复标题、段落和现有表格；页面字符缓存逐页释放。
- 书签优先定位标题；无书签时结合字号、加粗、独立间距和编号判断。列表项保持独立，缩进续行随原项。
- 跨页正文仅在同章节、前页靠近底部且末行接近右侧边界、后页从顶部继续、前句未结束时合并，保留两页区域。标题、表格和列表阻断跨页衔接。
- 切片聚合其覆盖的所有原文区域；正文和表格继续按版面交错排列，现有行切片和 Token 上限不变。
- 解析版本为 `pdf_single_column_v4`，附件与知识库启动恢复均识别旧版本并重建；人工清空索引的文档仍遵循原有排除规则。
- 完整图按同一页面渲染后的连通几何与内嵌栅格区域裁剪，保留矢量线条、箭头和图内文字；图内标签从普通正文中排除。图注按水平和上下距离匹配，同页多图按最近距离及视觉顺序绑定。
- 正文切片在图片位置断开，入库事务结束时统一重排正文、表格和图片；图片描述仍遵守 Token 上限并绑定同一原图。
- 表格保留真实跨行跨列、多级表头、表题和物理行坐标；长表按完整行切分，每个引用片段只携带表头及实际召回行。
- 只要表格抵近前页底部、下一页从顶部开始且重复相同表头，才视为跨页续表；独立相邻表保持不同身份。
- 无法从文字可靠判断表头的数据矩阵自动渲染表格原区域截图作为本地兜底，不调用视觉模型；前端对可靠结构使用 React 跨行跨列表格，对兜底只展示受保护截图。
- 知识库图片缓存增加图注一致性检查：旧版没有图注的描述在重建时重新生成，不能覆盖新解析得到的图注。真实样本的上传和重试验收使用受控 HTTP 协议替身，不向真实外部模型发送样本。
- 标题和段落判断属于启发式，当前样本通过不代表所有单栏 PDF 均可完美还原。

## 第二阶段真实样本结果

正式受限工作进程解析同一 20 页样本：6 张完整图均成功裁剪，均为约 1015×438 像素，且分别绑定图注；图注位于裁剪区域外，图片内标签不再重复进入正文。所有内容块仍保留物理页与 point 坐标。

真实流程图的独立内容流回归还覆盖：无内嵌栅格图的矢量流程图裁剪、同页左右两图按视觉位置绑定图注、表格截图兜底、两层表头、横向/纵向合并、整行表题、跨页续表，以及独立相邻表不误合并。

## 验证方式

真实样本路径通过 `PDF_ACCEPTANCE_SAMPLE` 注入测试，不把用户 PDF 原件加入版本控制。`tests/attachments/test_pdf_layout.py` 同时保留可独立运行的小型真实内容流回归，覆盖书签、列表续行、坐标、跨页及加粗编号标题。

先观察真实样本失败，再逐项实现：标题缺失、重复页边内容、标识符割裂、列表续行断裂和跨页段落分别完成失败到通过的验证。现有表格上传、检索、阅读、旧版恢复和知识库格式回归 20 项通过；严格类型检查 134 个文件通过。

最终完整后端回归在一次性隔离 PostgreSQL 上 **270 passed**（358.93 秒），包含用户真实样本与全部 PDF／知识库集成路径；严格类型检查 **147 个文件通过**，78 个新增／修改函数已检查中文用途注释，差异空白检查通过。仅有原有 pypdf 配置弃用提示。Browser 回归共 22 项通过，覆盖 PDF 上传、结构化表格、表格截图、图片、搜索、来源删除和移动端布局；前端生产构建通过。
