# 单栏文字型 PDF 结构解析验证

2026-10-23。第一阶段范围为内容结构、原文位置及正文／表格顺序，不包含完整图区域裁剪、复杂表格重建或图片切片统一排序。

## 真实样本对照

用户提供 20 页、有文字层、单栏的架构规范 PDF，包含 6 张内嵌栅格图；文档没有书签。对照渲染后的第 1–3 页，并检查全文解析结果。

| 项目 | 修改前 | 修改后 |
| --- | --- | --- |
| 标题 | 无标题类型，每页合成一个大段落 | 20 个一级标题、74 个二级标题，正文携带章节路径 |
| 页边内容 | 页眉、页脚及页码进入正文，页脚还会排在正文前 | 根据跨页重复及边缘位置清理 |
| 段内换行 | 中文词和 `Ingress` 等标识符被割裂 | 恢复自然段及中英混合标识符，元信息行分别保留 |
| 图注 | 6 张图片的图注均为空 | 6 张全部绑定；已绑定图注不进入普通正文 |
| 位置 | 只有页码，无区域 | 全部内容块带物理页和左上角 point 坐标 |

正式受限工作进程输出：20 页、94 个标题、304 个非空内容块，另保留 6 个移除图注后的空单位以兼容现有处理流程；6 张图片均有图注。坐标保存在切片现有 JSON 结构中，不新增重复正文表。

## 实现与兼容

- PDF 先统计正文／标题字号及重复边缘行，再逐页恢复标题、段落和现有表格；页面字符缓存逐页释放。
- 书签优先定位标题；无书签时结合字号、加粗、独立间距和编号判断。列表项保持独立，缩进续行随原项。
- 跨页正文仅在同章节、前页靠近底部且末行接近右侧边界、后页从顶部继续、前句未结束时合并，保留两页区域。标题、表格和列表阻断跨页衔接。
- 切片聚合其覆盖的所有原文区域；正文和表格继续按版面交错排列，现有行切片和 Token 上限不变。
- 解析版本为 `pdf_single_column_v3`，附件与知识库启动恢复均识别旧版本并重建；人工清空索引的文档仍遵循原有排除规则。
- 图片仍走既有提取和视觉描述链路。本次只修复图注分块，不宣称支持完整矢量图裁剪、多图坐标匹配或图片切片原文顺序。
- 知识库图片缓存增加图注一致性检查：旧版没有图注的描述在重建时重新生成，不能覆盖新解析得到的图注。真实样本的上传和重试验收使用受控 HTTP 协议替身，不向真实外部模型发送样本。
- 标题和段落判断属于启发式，当前样本通过不代表所有单栏 PDF 均可完美还原。

## 验证方式

真实样本路径通过 `PDF_ACCEPTANCE_SAMPLE` 注入测试，不把用户 PDF 原件加入版本控制。`tests/attachments/test_pdf_layout.py` 同时保留可独立运行的小型真实内容流回归，覆盖书签、列表续行、坐标、跨页及加粗编号标题。
