# 会话文档通过工具按需读取

2026-10-20：文字附件不论大小均不自动加入模型上下文，替代 ADR 0009 的全文注入决定。每轮重新提供文档 ID、文件名和页数（非分页文件为段落数）的清单，不提供状态或解析缺口。正文、切片及索引只属于原会话，不进入长期记忆；图片沿用 DeepSeek file_id 链路。

PDF 使用原有物理页；Word 保存原文件并由后台自动排版为固定 PDF 副本，后续页码以副本为准。解析原文保留页、段落及段内位置，检索切片保存到原文的映射。TXT、Markdown 使用段落位置。全部文字文件均切片；切片大小和返回数量是独立策略，不按检索结果 Token 数裁剪。

只暴露 search_documents 与 read_document 两个工具，由模型自主决定是否、何时以及以何种顺序调用，不增加任务分类、前置检索或总结流程。前者返回固定数量的完整切片；后者从解析原文按范围读取，单次最多 min(10,000 Token, 当前可用上下文预算)，超限返回部分原文及精确续读位置。计数优先使用对应模型官方 Tokenizer／计数接口，没有对应实现才按字符保守估算。每次回答中两个工具分别最多执行五次，正常、失败、重试及续读均计入，后端执行限制。

所有附件从上传登记成功开始保留 30 天，不滑动续期；到期先禁止访问，再重试清理原文件、分页副本、原文、切片及索引，图片同时清理远端身份。已生成的聊天正文保留。主动删除沿用现有来源撤回和清理合同，迟到处理结果不得恢复来源。工具正文可随上下文压缩移出，持久内容及每轮清单仍支持重新读取。

## 实现边界

当前代码未实现滑动窗口／摘要压缩，也没有现成预算接口；本次不另建压缩机制。原文读取在执行点根据实际消息、工具定义、已返回工具结果及模型窗口／输出预留计算剩余预算，并预留包装开销。窗口与输出预留作为模型配置保存，可供后续压缩机制直接接入。

初版保留当前 1,500 字符分片作为可配置默认值，默认返回五片；采用支持中英文的关键词倒排索引检索，不新增外部嵌入服务依赖。Word 分页使用 LibreOffice，部署必须安装对应运行时和中文字体；缺少运行时或转换失败时明确处理失败，不能伪造页码。原有文档在启动时从原文件重建知识库，仍遵守原上传时间 TTL。
