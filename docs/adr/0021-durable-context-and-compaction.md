# 通过检查点续接执行并按输入预算压缩工作上下文

2026-11-01：替代 ADR 0012/0020 中“不恢复图执行”的选择。用户要求服务重启后显式点击“继续执行”，因此外层会话图使用稳定会话线程，主、子工具循环各自使用执行线程，统一接入官方 PostgreSQL checkpointer。外层保存内部执行的业务关联，恢复时重新创建客户端、Skill 会话和子任务调度；不尝试恢复 Python 栈或模型网络连接。检查点同步提交，原始消息、用量、文件及副作用记录仍由业务存储管理。

每次模型调用前通过独立准备节点按完整输入预算压缩早期完整交互；默认 75% 触发、50% 目标。摘要作为带标记的资料消息保存在 State，近期消息及当前真实请求保留，系统及 Skill 指令每轮重新加载；当前用户的 Skill 描述仍保留全文。摘要不获得系统指令权限。超大历史分批总结，每批通过统一模型网关计量，失败不提交新摘要；无法容纳固定指令或当前请求时明确失败。会话消息水位避免下一轮重新合入已压缩历史，原始记录完整保留。

重启暂停原回答和主从身份，不自动重发请求；继续沿用原回答、操作和调用预算，重试创建新尝试。已完成工具结果复用；命令和发布使用稳定调用身份，实际命令中断不被误认为仍有进程。Skill 保存为后端机制，移除 save_skill_task。用户停止仍是终态。资料撤销事务清除相关派生检查点，完成线程收缩为最新快照和引用通道版本，删除会话清理线程；检查点版本不兼容时要求重试。
