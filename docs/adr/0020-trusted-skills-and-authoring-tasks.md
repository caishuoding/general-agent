# 可信 Skill 按需加载与独立制作任务

Status: accepted

完整接入 PPT Master，采用固定上游发行目录。主智能体每轮看到完整 description，自主调用加载工具；由加载器把管理员安装的入口及明确读取的 Markdown 作为可信任务指令注入唯一系统消息。普通附件、网页、工具输出仍是不可信资料。本决策补充 ADR 0008 的提示词组装规则，避免通用“不执行工具结果指令”与受信任 Skill 工作流相冲突；不通过关键词或额外模型预先路由。

制作任务独立于回答尝试持久化，用户确认后在新回答中显式续接；不恢复中断的模型网络请求，不重建 LangGraph checkpointer，保持 ADR 0012。主执行持有任务文件写入权限，子执行继续复用现有公共资料工具；上游角色切换不要求创建子智能体，保持 ADR 0017。

命令在独立 Docker 任务容器执行，工作目录按任务挂载；仅经公网代理访问外部服务，不挂载应用配置、其他任务和 Docker socket。后台持有 Docker 管理权限，部署时必须只开放受信任应用入口。预览通过短期能力令牌代理，在不透明源 CSP 沙箱运行；交付文件为独立不可变副本，下载重新核对所属会话与来源。
