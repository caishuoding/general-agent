# 唯一管理员与独立的管理端认证

Status: accepted (2026-10-28)

管理员固定为唯一的 `admin` 账号，不允许创建第二个管理员、改名或停用该账号，也不允许把普通用户提升为管理员。管理员与普通用户的凭据分别保存在同一个 PostgreSQL 数据库的不同表中；管理端和用户端分别验证凭据、保存登录会话并使用不同 Cookie，使同一浏览器可以同时保持两个入口的登录状态。访问 `/` 始终进入用户端，访问 `/admin` 始终进入管理端；在错误入口提交账号时统一返回“用户名或密码错误”，不透露账号属于另一个入口。

此决策取代 [ADR 0010](0010-precreated-accounts-and-admin-console.md) 中允许创建或调整管理员、共用账号表和跨入口登录会话的部分。拆分认证和存储增加迁移及维护成本，但避免管理身份影响用户端访问，也使两个入口的凭据边界与界面边界一致。
