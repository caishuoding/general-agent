# 主回答使用单图与稳定会话线程

Status: accepted

2026-11-01：用户确认将一次对话回答的准备、模型工具循环和收尾编排为一张图，并删除嵌套主图。本决策替代 ADR 0007/0012/0017 中固定外层图包裹内层主工具图的结构，以及 ADR 0021 中主回答按 Run 分离检查点的部分；显式继续、业务存储隔离、上下文压缩和副作用幂等要求继续有效。

主回答使用 `conversation_id` 作为 LangGraph 稳定 thread。同一会话新消息由框架加载已有 State；中断继续从同一线程的待执行位置恢复。主图固定为五个业务节点：`prepare_context`、`prepare_model`、`call_model`、`execute_tools`、`finalize`。自动结果信箱收取并入 `prepare_model`，结束前子任务和后台命令检查并入 `finalize`。子智能体仍按需使用独立 Run 图，但主、子图共享节点实现，主图节点不再启动第二张主工具图。

State 保留现有 AgentState 的工作消息、Skill、工具调用、轮次、失败及文档计数、子任务交付和回答字段，并加入主回答身份与失败信息。系统提示、工具定义、模型客户端、数据库连接、SkillSession 和调度器属于运行依赖，恢复时重建，不写入检查点。生成文件继续由 Skill 会话工作区和业务记录管理，不加入 State，也不新增跨轮上下文表。

最终提交、停止、资料撤销和工具副作用继续依赖业务记录与归属校验。检查点恢复可能重放未完成节点，因此所有会产生副作用的步骤保持幂等；旧拓扑检查点不能直接解释为新图执行位置。
