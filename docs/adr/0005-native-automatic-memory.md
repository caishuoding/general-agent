# 使用 Mem0 原生自动记忆和对话记忆工具

用户于 2026-10-16 明确取消逐条记忆确认，改用 Mem0 原生提取及新增、更新、删除判断；本决策取代 ADR 0004 中逐条确认与禁止自动推断写入的要求。Mem0 模型和嵌入配置由独立服务的官方 `/configure` 接口管理，业务后端不插入自定义提取模型适配器。

应用保留来源归属、稳定操作身份、删除后旧来源抑制，并提供查找、更新、删除记忆的对话工具；记忆文本与外部资料不构成工具操作指令。自动处理只使用本次获准的用户输入，不回填旧聊天、助手回答或附件。业务数据库不保留已取消流程的表、记忆正文、向量或 Mem0 history。
