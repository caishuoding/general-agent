# 文档切片按回答 LLM 计数，计数接口独立于模型服务商

2026-10-23：用户确认主要预算是最终回答 LLM 的上下文，当前使用 DeepSeek 官方分词器。本决定替代 [ADR 0011](0011-conversation-document-tools.md) 中“优先使用嵌入模型分词器”的选择：新文档切片及重叠按当前回答 LLM 计数，嵌入服务自身输入限制独立处理；召回后的文档阅读预算按本轮回答 LLM 重新计数。业务层统一调用 TokenCounter，内部按完整服务地址与模型精确选择官方分词数据，未知模型明确标记估算，不能套用相近模型的文件。

切片保留生成时的计数模型、方法和指纹；新任务重新读取模型配置，任务内部固定快照。切换 LLM 本身不要求重新切分全部已有资料，启动恢复仅比较切片结构预算及解析、视觉等规则；此前无结构指纹的旧版索引仍可升级一次。人工清空索引使用显式 index_cleared 标记阻止启动重建，知识库主动重试则重新生成。

图片描述的自动升级比较独立视觉规则版本，不能把聊天连接的配置修订当成规则变化。描述缓存仍记录实际模型修订；主动重试时可按新模型重新描述。只修改聊天模型、窗口或回答预留，不触发含图文档整份重切。
