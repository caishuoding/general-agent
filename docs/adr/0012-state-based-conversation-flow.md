# 对话节点通过 State 共享执行结果

2026-10-21：外层对话图统一使用 LangGraph State 传递历史消息、准备结果、工具循环后的消息、回答、来源和错误。prepare_context、agent、finalize 返回字段更新，后续节点从 State 读取；runtime.context 改为不可变的账号／会话／消息身份、模型配置、操作身份及传输模式，不再存放或修改 preparation、answer 和历史消息。

该决策替代 ADR 0007 通过修改运行上下文传递正文、仅将 failure 写入 State 的实现。消息字段表示完整消息快照，节点返回完整快照时使用默认覆盖语义，避免使用追加 reducer 重复拼接系统提示和历史。工具选择、文档清单与按需工具读取规则不变。

运行中共享数据与检查点持久化分开处理。当前应用重启会终止未完成网络请求，重试创建新的回答尝试，未使用外层检查点恢复；因此取消外层 PostgreSQL checkpointer 及其连接池，图仍以 State 正常执行。已生成消息、流式增量、操作幂等、用量和工具业务步骤继续由现有业务表持久化。旧 `langgraph` schema 不再写入，并已由迁移 052 整体删除；历史业务消息和调用记录不受影响。

流式文字回调只负责本节点的临时缓冲和现有 UI 增量存储；节点结束或失败时，将完整／部分回答返回 State。外层消费图的 values 流保留最新 State，图边界异常仍可据此收尾并保留部分内容。LangSmith 可直接观察各节点的输入输出；模型凭据和客户端不进入 State。

2026-10-23：流式回答允许在 `messages.progress` 保存一个临时进度对象，只包含当前关键工具的安全状态文案。知识库检索、资料读取、联网搜索、网页读取和子任务处理会覆盖该对象；回答开始输出后显示“正在整理回答”，完成、失败或停止时清除。该字段不记录步骤历史、工具参数或模型推理，现有 SSE 消息快照仍作为唯一传输方式，刷新和重连后按数据库中的最新状态恢复。
