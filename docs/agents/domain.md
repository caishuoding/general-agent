# Domain Docs

## 布局与读取时机

本项目采用 single-context 布局：

- 根目录 GLOSSARY.md 保存领域术语。
- docs/adr/ 保存架构决策记录。

探索项目、设计功能或修改实现前，阅读 GLOSSARY.md，
并阅读与当前工作相关的 ADR。

文档不存在时直接继续，不要求预先补齐。
领域建模技能会在术语或决策明确后按需创建文档。

## 使用术语

在规格、任务、设计和测试中使用 GLOSSARY.md 定义的名称。
需要的新概念尚未定义时，先判断是否确有必要，
有必要则交由领域建模流程补充。

## 决策冲突

方案与现有 ADR 冲突时，明确指出对应 ADR、冲突内容和重议理由，
再决定是否更新该决策。
