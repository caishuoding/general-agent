# 持久上下文与继续执行

应用启动先执行业务迁移，再初始化 `langgraph` schema。需要新依赖 `langgraph-checkpoint-postgres`；部署执行 `uv sync` 或使用更新的 requirements-server.txt。官方 saver 以独立自动提交连接运行，Python 调用使用同步 durability。

会话 thread_id 为会话 UUID；内部 thread_id 为 `run:<Agent Run UUID>`。`checkpoint_threads` 记录归属。State 带版本，外层携带回答 ID、历史位置、资料快照、工作消息和 Skill 运行快照。会话锁仅覆盖认领和每次检查点写入，不跨网络请求持有；写入校验原回答归属，停止后的迟到请求不能覆盖新回答的 State。连接、配置密钥不进入 State；检查点序列化剔除 reasoning_content，当前进程仍可按供应商协议使用推理续传。

外层按历史位置只合入新增消息，刷新当前记忆和附件材料。旧会话首次从业务历史初始化。重试使用截至原用户消息的历史及描述快照，生成新回答；继续使用原回答和操作，并重新调度未完成的子执行。`POST /api/conversations/{conversation}/messages/{message}/resume` 返回 202 和会话详情，重叠请求不会创建第二次执行。跨账号返回 404；版本、模型配置或资料变化时给出明确错误。正在生成时界面继续沿用现有 SSE。

应用重启将新版本生成记录标为 interrupted，保留草稿，不自动向模型发送请求。前端最新中断回答提供“继续执行”和“再试一次”。未完成模型节点重新调用时替换未完成草稿；明确停止仍为 stopped。等待继续的时间从截止期限中扣除，已用次数和调用账本不重置。

压缩位于每次模型调用前的图节点中，计算包含动态系统指令及工具定义。管理端高级设置提供触发比例和目标比例，默认 75%/50%，预算先扣除回答预留和协议余量。摘要作为资料消息注入，完整当前需求、系统/Skill 指令、最新必要组和未配对工具调用保留；已完成工具调用与结果一起总结。历史超过摘要模型窗口时分片合并，所有摘要请求仍记录真实调用用量。摘要失败不提交压缩后的 State；不足以容纳固定内容时明确停止。

Skill 活动任务、入口版本和指令摘要自动保存；服务重启恢复时重新核对实际文件。命令登记绑定执行和原工具调用身份，重复步骤返回原命令，不因 interrupted 状态自动重发命令。交付文件绑定稳定发布身份，重放不覆盖已交付副本。回答结束自动转 waiting，不凭后端规则推断业务“制作完成”。

资料撤销清理对应会话和执行检查点。维护过程跳过仍在执行的会话，完成线程保留最新快照及所引用的 blob；删除会话和孤立线程被清理。暂停中的检查点保留供继续使用。运行中的图节点仍需重新鉴权，检查点不是工具副作用恰好执行一次的保证。
