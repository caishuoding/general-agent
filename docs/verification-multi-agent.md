## 2026-10-28 流式断线续写与共享联网额度

模型流式连接中断、响应超时或缺少结束标记时，回答图保留已收到的正文并在同一执行内最多尝试三次。尚无正文时重发原请求；已有正文时把原上下文、assistant 前缀和临时续写要求发送给模型，恢复后的第一段正文前写入内部标记，由前端渲染为持久断点。“复制回答”会移除该内部标记。认证、参数、上下文和输出长度错误不进入恢复循环；三次仍失败时返回明确的连接恢复失败。

搜索与 Fetch 改由每个智能体的 `web_count` 共享额度控制，合计最多六次真实外发，内部重试逐次计数。第七次开始同时禁用两个工具，其他智能体及新回答独立计算。迁移 `059_combined_agent_web_budget.sql` 从旧 `search_count + fetch_count` 初始化该值。
