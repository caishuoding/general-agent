# 原生自动记忆验证（2026-10-16）

用户授权普通对话使用 Mem0 原生自动记忆，取消新聊天事实的逐条确认。当前聊天配置同时用于原生提取和变更判断；本机现有配置为 DeepSeek。管理页保留查看、编辑、删除及来源，智能体注册 `search_memories`、`update_memory`、`delete_memory` 三种真实工具。

## 实现边界

- 使用固定 Mem0 OSS 1.0.11 的 `add(infer=True)`、原生相关记忆检索和 ADD/UPDATE/DELETE/NONE 判断，应用接管预算计量、来源、稳定身份、版本检查与完整删除。
- 原样明确保存和精确更新/删除命令继续支持。自然语言操作先查找有效条目，再执行本次用户要求的更新或删除；当前每次请求操作一条具体记忆，歧义时澄清。
- 新聊天不再产生候选确认卡；旧候选保持原状态。附件的明确提取与人物归属核对流程保持独立，不自动读取旧附件或回填旧聊天。
- 已付费推理、嵌入及工具回合有来源绑定的恢复点；停止、来源删除和忘记记忆会使相关旧执行失效。自动记忆失败不冒充保存，聊天完成后可独立重试。
- 新迁移 020 使用 PostgreSQL 保存自动状态、恢复点及工具观察版本；没有新增 LLM 密钥或配置文件。
