# Mem0 2.2.1 升级验证（2026-10-17）

项目依赖已从 `mem0ai==1.0.11` 升级为 `mem0ai==2.2.1`，并通过 `uv lock` 与 `uv sync --locked` 安装到项目虚拟环境。

## 检索行为

Mem0 2.2.1 的 PGVector 检索路径由 SDK 内部融合语义向量、PostgreSQL BM25 关键词和实体加权；应用继续只负责用户、来源、版本和删除后的有效性校验。应用适配层不再反转 2.2.1 已返回的相似度分数，并改用 2.x 的 `filters` 与 `top_k` 参数。

## 适配变更

- 固定并校验 `mem0ai==2.2.1`。
- 使用 Mem0 2.2.1 官方 `SQLiteManager` 管理 history；PostgreSQL 只由官方 PGVector 保存正式向量。
- 兼容 PGVector 的 `top_k` 参数和 2.x 的消息列表写入格式。
- 2.x ADD-only 自动写入结果回接应用来源账本，不重复写入向量或历史。
- 保留应用自己的预算、来源守卫、删除和恢复边界。

## 结果

| 检查 | 结果 |

| 严格 Mypy（79 文件） | 通过 |
| Mem0 PostgreSQL 生命周期测试 | 通过 |

2.2.1 的自动记忆算法与 1.x 不同：当前 SDK 使用 ADD-only 提取和新的提示词/批量写入流程。旧测试替身仍匹配 1.x 的 `facts`、UPDATE/DELETE 提示词，因此不能把旧套件失败解释为真实 2.2.1 服务失败；生产真实模型联调仍需单独验收。
