# 扫描 PDF 版面 OCR 验证

日期：2026-10-26。审查基线：`3e45617628c61d7122ea32bbc1182c324c134658`。本轮按用户确认先更新规格与任务，再修改代码；代码提交于当前 `fenzhi1` 分支。

## 实现

- 受限进程检查原 PDF，并按页区分原生文字页与缺少文字层的整页扫描图；扫描页单独受限渲染。
- 固定版本的 PP-StructureV3 服务常驻，识别方向、正文、表格、插图区域及阅读顺序；业务应用不加载 OCR 模型。
- 文字和可靠表格转换为现有 DocumentUnit；插图从扫描页裁出，图注与图片一起进入现有视觉描述。整页误判为图片区时保留正文、标明缺口并跳过整页视觉描述。
- 图片按实际图注区域去重，图内标签不重复进入正文；坐标逆映射回原始 PDF，媒体与文字按 OCR 阅读顺序排列。
- 整份中间结构及图片描述准备完成后统一切片，附件/知识库复用算法并分别存储。正文为 text 来源、表格为 table 来源、插图为 image 来源。
- 无法确认表头的表格保留纯文字和截图，文字按 Token 预算无重叠分片，结构只携带实际本片文字与同一截图身份；旋转页暂不依赖原页上下边缘猜测续表。
- OCR 页失败、低置信度、页进度和规则版本有明确记录；删除或撤销后不发布迟到内容；解析升级保留附件原 TTL 和人工清空标记。

## 真实模型验证

独立测试环境安装 PaddleOCR 3.3.2、PaddleX 3.3.13、PaddlePaddle 3.2.2，下载官方模型并在本机 CPU 启动服务；没有使用私人文件或调用外部聊天模型。

- 合成英文印刷体扫描 PDF：真实 PP-StructureV3 验收测试通过（17.99 秒），识别出 `R-2048`、检查周期，并经公开解析入口保留原页坐标。
- 合成中文图文表格扫描 PDF：完整流程约 22.71 秒。正确提取风险编号与巡检正文，流程图裁出并绑定“图1设备维护流程”；表格未提供可靠显式表头，按设计保留纯文字和原区域截图。
- 中文样本负责人字段存在漏字：原文“负责人：林女士”识别为“负责：林”。置信度不等于准确率保证，本轮没有宣称中文人名、低清扫描、印章或手写体已通过质量验收。
- 中途用户中断使一次后续中文请求超时；恢复本机验证服务后重新执行成功。中断的完整套件没有计入通过结果。

真实服务证实了版本、输出结构、裁剪和引用链路可运行；真实业务文档准确率仍需用户样本验收。第一版不持久化 OCR 中间正文缓存，失败重试会重新 OCR。
