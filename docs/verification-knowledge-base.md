# 独立知识库验证记录

日期：2026-10-23。

## 交付范围

知识库页面支持创建、重命名、上传、下载、失败重试与删除；会话可选择多个自己的知识库。后台区分上传和解析、图片描述、切片、向量索引的真实进度，单图失败和向量失败明确显示。原件、分页副本和图片保存在 `APP_DATA_DIR/knowledge/<文档 UUID>/`，迁移 049 的知识库切片及图片表与附件完全独立。

切片预算、表格规则、BM25、余弦排序、RRF、智谱重排及降级共用现有算法。知识库在入库时生成向量；模型自主调用 `search_knowledge(knowledge_base_id, query)`，只在会话已选且账号拥有的知识库中召回。图片描述由已有视觉链路生成，命中时在下一轮模型请求提供原图。
