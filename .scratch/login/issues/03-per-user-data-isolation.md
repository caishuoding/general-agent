# 03: 聊天、附件、记忆、搜索与用量的账号隔离

**What to build:** 把所有现有业务接口接入当前登录账号，按账号过滤会话、附件、记忆、搜索记录和用量；Mem0 使用账号 UUID 作为用户标识，不同账号的数据不能互相读取。

**Blocked by:** 02.

**Status:** ready-for-agent

**规格覆盖：** 登录与后台账号管理规格，用户故事 14、15；实现决策中的权限边界、数据归属和 Mem0 隔离。

- [ ] 会话创建、列表、读取、删除和流式订阅都按当前账号过滤。
- [ ] 消息、附件上传、附件下载、附件删除和来源删除都验证会话归属。
- [ ] 自动记忆、召回、更正、删除和记忆工具使用当前账号 UUID，不再使用固定 `local-person`。
- [ ] 搜索请求、模型调用和用量列表按当前账号记录与返回。
- [ ] 普通用户访问他人资源时返回未找到或禁止访问，不泄露资源是否存在。
- [ ] 现有配置接口改为仅管理员可读写；普通用户不能读取密钥状态或修改配置。
- [ ] 测试覆盖两个账号的会话、附件、记忆、搜索和用量隔离，以及跨账号直接访问被拒绝。
- [ ] 所有新增或修改的函数都有中文用途说明注释。
