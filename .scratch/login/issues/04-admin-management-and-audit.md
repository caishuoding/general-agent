# 04: 管理员账号管理与跨账号只读查看

**What to build:** 提供管理员后台接口：列出和创建账号、停用或启用、重置临时密码；只读查看所有账号的会话、消息、附件、记忆、搜索和用量，并记录审计。

**Blocked by:** 03.

**Status:** ready-for-agent

**Completion:** complete（2026-10-19）。

**规格覆盖：** 登录与后台账号管理规格，用户故事 7–13；实现决策中的账号、权限边界和审计。

- [x] 管理员可以创建普通用户和其他管理员，并为新账号设置临时密码。
- [x] 管理员可以停用、启用账号和重置临时密码；停用或重置后吊销该账号全部会话。
- [x] 最后一个有效管理员不能被停用或降级。
- [x] 管理员可以列出所有账号及状态，并只读查看指定账号的会话、消息、附件、记忆、搜索和用量。
- [x] 管理员可以下载指定账号的附件，但不能调用发送消息、修改记忆、删除会话或删除附件的写接口。
- [x] 管理员查看他人内容时写入包含管理员、目标账号、资源类型、资源标识、动作和时间的审计记录。
- [x] 普通用户访问后台接口返回禁止访问。
- [x] 测试覆盖创建、停用、启用、重置、最后一个管理员保护、只读边界和审计记录。
- [x] 所有新增或修改的函数都有中文用途说明注释。
