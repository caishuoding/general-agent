# 06: 前端管理员后台

**What to build:** 增加仅管理员可见的后台页面，支持账号列表、创建账号、停用或启用、重置密码，以及按账号只读查看会话、消息、附件、记忆、搜索和用量。

**Blocked by:** 04, 05.

**Status:** ready-for-agent

**Completion:** complete（2026-10-19）。

**规格覆盖：** 登录与后台账号管理规格，用户故事 7–13；实现决策中的前端和权限边界。

- [x] 后台账号列表显示用户名、角色、状态、创建时间和最近登录时间。
- [x] 管理员可以创建普通用户或管理员，并输入临时密码。
- [x] 管理员可以停用、启用账号和重置临时密码，操作结果明确可见。
- [x] 管理员可以进入指定账号的只读详情，查看会话、消息、附件、记忆、搜索和用量。
- [x] 附件下载可用，页面不提供代发消息、修改记忆、删除会话或删除附件入口。
- [x] 普通用户直接访问后台路径时被拒绝并回到聊天界面。
- [x] 浏览器测试覆盖创建账号、停用、重置、只读查看和普通用户访问拦截。
- [x] 所有新增或修改的组件和函数都有中文用途说明注释。
