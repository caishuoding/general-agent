# 02: 登录、服务端会话与强制改密

**What to build:** 提供登录、退出、读取当前账号和修改密码接口；使用服务端不透明会话和安全的 HttpOnly Cookie；首次登录与管理员重置后强制改密；初始管理员改密前拒绝公网登录。

**Blocked by:** 01.

**Status:** ready-for-agent

**Completion:** complete（2026-10-19）。

**规格覆盖：** 登录与后台账号管理规格，用户故事 1–6、15；实现决策中的初始管理员、密码和登录会话。

- [x] 登录接口按用户名和密码验证账号，失败统一返回“用户名或密码错误”。
- [x] 登录成功创建服务端会话，Cookie 设置 `HttpOnly`、`Secure`、`SameSite=Lax`，有效期 7 天。
- [x] 退出删除当前会话；改密和重置密码吊销目标账号全部旧会话。
- [x] 所有新账号和重置密码后的账号首次登录必须改密；改密前除当前账号、退出和改密接口外全部拒绝。
- [x] 初始管理员改密前只接受本机或 SSH 隧道登录，不接受可信反向代理转发的公网请求。
- [x] 密码使用 Argon2id；新密码至少 10 位、不能等于用户名并拒绝常见弱口令。
- [x] 当前账号接口不返回密码哈希或会话令牌。
- [x] 测试覆盖正确与错误登录、停用账号、会话过期、退出、改密、旧会话失效、强制改密和初始管理员来源限制。
- [x] 所有新增或修改的函数都有中文用途说明注释。
