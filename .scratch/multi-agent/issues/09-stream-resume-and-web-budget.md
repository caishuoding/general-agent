# 流式断线续写与共享联网额度

## 范围

模型流式连接在完整结束前断开时，保留已收到正文并在同一回答内自动重试，最多总计三次请求。已有正文时，将原上下文和 assistant 前缀重新发送，通过临时用户指令要求从末尾直接续写、不重复且不重跑已完成工具。前端显示连接恢复进度，并在真实断点保留“连接中断 · 已自动恢复并继续”标记；复制回答时移除内部标记。

搜索与 Fetch 两个联网工具改为每个智能体共用一个六次外发额度。额度计数包含两个工具及后端内部重试，耗尽后同时禁用两个工具。保留旧分类计数和历史调用记录。

联网工具是否已经获得足够信息仍需研究。当前缺少充分性、覆盖度、来源质量和边际收益判断，常常接近最大额度后才停止，该事项已记录在[对话附件 TODO](../../conversation-document-tools/TODO.md)。

## 验收接口

- 模型边界用网络断开或缺少结束标记触发 `ModelConnectionFailure`，验证最多三次实际请求、每次独立用量、前缀续写与持久断点标记。
- 认证、参数、上下文和输出长度错误不进入连接恢复循环。
- 搜索与 Fetch 使用受控外部 HTTP 验证前六次真实请求可执行，第七次被统一额度拦截，后续模型请求同时隐藏两个工具。
- 验证迁移 `059_combined_agent_web_budget.sql` 把历史 `search_count + fetch_count` 合并到 `web_count`。
