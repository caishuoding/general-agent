# 根回答预算、停止传播、超时与来源清理

## 依赖与范围

依赖 [02](02-orchestration-tools.md)、[03](03-agent-runtime.md)、[04](04-source-delivery.md)。根回答统一管理调用预算、总时长和活动子任务，接入停止、失败、结束、重启和会话／来源删除。

## 验收

- 根预算在外发前原子预留；并发模型与搜索不能共同超额，创建幂等不重复扣额度。排队、模型等待与工具执行均受截止时间约束。
- 用户停止时先冻结业务终态并关闭分派，取消全部活动子执行并唤醒等待；已发请求可记录真实 usage，但不能追加正文、交付结果或恢复状态。
- 主智能体失败或正常最终回答时不遗留后台任务；子执行失败、超时以结构化结果交给主智能体，不自动无限重试。
- 启动将未完成执行标为中断失败，重试创建新回答身份。停机取消后有界等待，不因网络阻塞无限 join。
- 会话／附件／知识库来源删除纳入新增记录与证据清理；外键不阻塞原有删除，原调用账本按既有规则保留，跨账号无影响。
- 工具接口及聊天 HTTP/SSE 验证排队取消、运行取消、迟到成功、并发额度与结束竞态；不使用真实密钥和计费调用。
