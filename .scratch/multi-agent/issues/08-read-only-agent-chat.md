# 子智能体只读会话界面

## 范围

按[规格](../spec.md#子智能体只读会话)为每个子智能体提供可打开的只读聊天线程。主回答继续显示轻量任务和公开结果；子线程展示主智能体派工、系统状态、子智能体历次回复和实际来源。用户不能在子线程输入、追加或单独重启任务；停止整个回答仍取消全部子任务。

## 验收接口

沿用 Agent 编排 API 和聊天 HTTP/SSE 到受控模型的公开接口。覆盖多执行轮次顺序、账号隔离、来源撤销、只读交互、主对话结果入口及刷新恢复。代码审查基点为本次开始前的 `HEAD`。
