# 主从模型循环、上下文与工具权限

## 依赖与范围

依赖 [01](01-execution-records.md)、[02](02-orchestration-tools.md)。保留外层三节点图，主从复用通用 AgentToolGraph。主智能体新增四工具，自主决定分工；子智能体仅运行独立工具图，不执行自动记忆或外层消息收尾。

## 验收

- 普通问题可直接回答，不增加强制规划请求。主模型发出 spawn 后接到 ID 再次调用，能够自己使用工具、继续创建或等待。
- 两个受控子任务可同时调用模型；消息、工具结果、图片注入集合和失败额度相互隔离。模型默认同配置，调用均经统一网关计量。
- 子智能体只接收任务、必要背景、交付要求与有效资料说明，不默认复制会话。补充任务延续其上下文，超预算明确失败。
- 子智能体不能创建下一级、操作记忆或扩大资料范围，即使伪造工具调用也被后端拒绝；附件与知识库权限在实际读取核验。
- 子输出写任务记录，不追加用户回答、不触发 Mem0；只由主智能体综合输出。
- 在聊天 HTTP 到受控模型 HTTP 的接口验证真实请求序列和参数，保留现有单智能体回归。新增修改函数及回调均有中文说明。
