# LLM 分词计数与统一适配接口

## 用户确认

2026-10-23：切片和重叠按最终回答 LLM 的 Token 计数，当前使用 deepseek-flash 的官方离线分词器；嵌入模型不再决定切片计数模型。切换模型服务商时，外层计数接口不变。

## 合同

- 外层统一使用 TokenCounter 的 count、prefix、available；按完整模型连接配置选择适配器，服务商细节只在计数模块内处理。
- 官方 tokenizer.json 按 endpoint + model 精确注册，相对路径以应用数据目录为基准，加载前校验 SHA-256；不得根据相似模型名猜测匹配。保留既有 MODEL_TOKENIZERS 显式映射兼容。
- 官方离线文件只计算普通文本 Token；available 对协议包装保留余量，整轮真实输入仍参考模型 usage。未知模型明确标记 character_estimate；显式配置损坏必须报错，不能伪装成官方计数。
- 当前安装官方文档提供的 DeepSeek V4 分词数据，提供可重复运行的安装脚本并记录来源、校验值。只读取分词数据，不执行下载的代码。
- 新处理的附件和知识库文档按当前 LLM 选择计数器，每次处理固定一个计数快照并保存实际模型、方法及指纹。已有切片不因 LLM 切换自动全部重切；结构预算、解析或视觉规则变化仍可升级。
- 召回后的阅读预算按当前回答 LLM 计数，原有工具、表格、重叠、权限和独立存储合同保持。嵌入服务自身输入上限独立约束。
- 本次切片与图片的人工清空状态应保留；启动恢复跳过明确标记 index_cleared 的文档，用户主动重试时重新生成。

## 验收

统一计数接口验证精确路由、损坏配置、不同模型隔离、原文前缀预算、模型配置切换；附件与知识库验证新任务用 LLM 计数、旧切片保留与清空标记。真实官方资产离线计数单独验证；运行类型检查及完整后端测试。
