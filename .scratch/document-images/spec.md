# 会话文档内嵌图片理解

Status: ready-for-agent

## 目标

Word 与 PDF 解析时需要提取文档内嵌的栅格图片。每张图片通过当前配置的
视觉模型生成结构化描述，描述作为独立切片参与现有文字检索；切片绑定原图，
工具召回后把描述和原图一起交给模型。当前配置为 `deepseek-flash`。

## 必须行为

- Word 从 DOCX 图片关系和图片媒体中提取图片，并保留段落及章节位置。
- PDF 提取页面内嵌栅格图片；只有图片、没有文字层的扫描页仍可处理。
- 视觉模型返回可明确读取的文字、图注、完整描述和不确定项。
- 每张图片的描述形成至少一个文本切片，切片携带稳定且全局唯一的 `image_id`。
- `search_documents` 与 `read_document` 的结果携带 `image_id`。
- 文档工具召回图片切片后，下一次模型请求同时包含切片文字和对应原图。
- 同一回答中重复命中的图片只发送一次。
- 图片描述失败不能破坏文档中已经可用的正文；失败状态必须真实可见。
- 图片原文件、远程身份、描述、切片和向量随附件删除或到期一起清理。

## 第一版边界

- 只处理可由 Pillow 解码并转换为 PNG 的常见栅格图片。
- 暂不解析 SmartArt、EMF、WMF、矢量图表及 Markdown 外部图片引用。
- 每份文档最多处理 50 张图片；超出部分在解析说明中标记缺口。
- 视觉模型不可用时保留正文，图片标记为描述失败并允许以后重建。

## 验证接口

- 上传含图 WORD／PDF，等待附件可用。
- 通过 `AttachmentService.documents.search` 检索视觉描述，并取得 `image_id`。
- 通过 `AttachmentService.documents.read` 按页取得同一 `image_id`。
- 通过真实聊天工具循环确认召回后的模型请求包含对应文件身份。
- 删除和到期清理后，图片记录、派生文件及切片不可访问。
