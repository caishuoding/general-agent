# 对话附件功能待办清单

更新时间：2026-10-28

以下研究与实际使用测试尚未完成；已有受控自动化回归不代表这些项目已验收。

## 主要未完成项

- [x] 扫描 PDF 版面 OCR、插图裁剪与共用切片已完成（2026-10-26），见[规格与验证](../pdf-scan-ocr/spec.md)；实际资料识别质量仍需用户样本验收。
- [ ] 尚未系统研究并验证何时启用多智能体。现有独立任务默认并行的规则仍需用真实任务对比单智能体与多智能体的回答质量、总耗时和调用成本；拆分、等待及汇总可能使多智能体反而更慢。
- [ ] 尚未研究多智能体间何时直接通信、何时通过中间共享 State 传递信息。现阶段子智能体不彼此直接通信，结果经信箱交付主智能体；需要比较两种方式的适用场景、信息时效、并发冲突、权限边界和追踪可读性，再决定是否调整现有设计。
- [ ] 联网搜索工具停止条件判断还未设置。现状是缺少结果充分性、信息覆盖、来源质量和边际收益判断，往往达到最大重试次数才停止；需要补充真实任务对比并设置可验证的停止规则。
- [ ] 尚未测试联网搜索质量。
