# 会话附件按需检索与原文读取

最终需求和边界见 [ADR 0011](../../docs/adr/0011-conversation-document-tools.md)。本规格取代旧附件全文输入方案，图片 file_id 调用保持不变。不要设计模型使用工具的任务路由或调用顺序。

## 验收

- 文档大小不影响路径；首轮及后续模型请求只自动收到精简清单，不自动收到正文。
- PDF 与 Word 具有固定页码、页内段落和续读位置；Word 原件和分页副本均持久保存。
- 两个工具仅访问当前账号、当前会话的有效文档。检索按配置的片数返回完整切片，不做 Token 截断。
- 原文读取返回连续文字，最多 10,000 Token 且不超过实际剩余上下文；超限返回准确游标，可无损连续读取。
- 每轮每个文档工具最多五次，含失败与续读；同批调用也受限，新回答重置。
- 全部附件 30 天到期，立即停用；原件、副本、原文、索引及图片远端身份可恢复清理，已完成聊天正文保留。
- 原有附件可迁移，重启可用；来源删除和图片调用回归通过。
