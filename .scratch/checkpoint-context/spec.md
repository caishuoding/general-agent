# State 检查点、上下文压缩与显式续接

以本次对话确认的完整流程为规格；基准提交 213940109458955511ab6a84681fd451dcd8dc9a。

- PostgreSQL LangGraph checkpoint 覆盖外层会话图及主、子 Agent 工具循环。会话使用稳定线程，内部执行按 Run 区分；不保存客户端、连接、密钥、私有推理。
- 原始用户消息、Skill 名称、回答、文件及用量业务记录保持独立。工作上下文从检查点恢复，只合入新消息；重试创建新回答，恢复沿用原回答和执行。
- 每次模型调用前核算系统提示、可信 Skill 指令、消息、摘要、材料和工具定义。默认可用输入预算 75% 触发、50% 目标，可配置。压缩模型调用经统一用量网关。
- 压缩早期完整交互组，保留当前请求、当前 Skill 描述、有效系统指令、近期必要消息、未完成工具调用。摘要覆盖目标/约束/变更/决定/结果/待办/关键文件标识，并保持原资料的信任级别。摘要先校验后提交；失败保留旧 State；超大摘要输入分批处理。
- 摘要作为 State 保存并在后续请求注入，不删除原始聊天记录；资料撤销使相关派生摘要及检查点失效。旧会话从业务历史初始化。
- 服务重启不自动续跑；未完成回答显示“继续执行”，点击从原检查点恢复。用户停止仍为明确终止，重试与继续分开。续接验证账号、最新回答、资料和 Skill 版本及模型配置；重复点击不启动多份执行。
- 未完成模型请求重发，原草稿保留至实际重发时替换，已完成模型/工具步骤复用。工具副作用按稳定调用身份核对，命令状态不等同于进程存活，不盲目重复执行未知结果的命令。
- Skill 任务/有效指令/命令关联自动保存和还原；移除要求模型调用 save_skill_task 的持久化职责与工具，结束回答可自动转等待。
- 主子执行恢复需重新建立调度，保留已保存结果和交付去重，不重置已用次数和用量。用户等待时间不计入执行时限。
- checkpoint 有版本、删除与保留策略，不无限累积；会话/来源删除清理派生状态。
- 更新 ADR 0012/0020，记录新决策；所有新增/修改函数必须有中文用途注释。
