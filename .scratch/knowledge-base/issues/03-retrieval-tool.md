# 知识库混合召回与对话工具

Status: ready-for-agent

Completion: complete（2026-10-23）。验证见[知识库验证记录](../../../docs/verification-knowledge-base.md)。

## 依赖与范围

依赖 [01 独立存储](01-storage.md) 和 [02 文档入库](02-ingestion.md)，落实[知识库规格](../spec.md)的召回与对话合同。

- 通过各自数据访问接口复用 BM25、向量余弦召回、等权 RRF、智谱重排和降级规则，保持附件工具行为。
- 注册 `search_knowledge(knowledge_base_id, query)`，不接收文件 ID；调用前限定账号、当前会话已选知识库和有效文档范围。
- 每轮提供已选知识库 ID／名称清单，由模型决定是否调用；一次工具查询指定库中的全部可检索文档，每次回答最多执行五次。
- 返回完整切片、知识库和文档来源、位置、图片绑定及真实降级信息；区分未选择、未就绪、无命中和失败。
- 命中图片后，下轮请求发送描述与正确原图，按既有规则去重和限制单批数量；远端过期后从知识库本机原图重传。
- 停止、删除和取消选择后，迟到结果不得继续注入上下文；复用现有执行与用量记录入口。

## 验收

验证跨库／跨账号隔离发生在召回前、多个文档候选、向量与重排降级、图片注入去重和远端过期、取消选择及删除竞态，并通过模型 HTTP 边界确认实际工具参数和图文请求。遵守函数说明注释规范。
