# 知识库管理页面与会话选择

Status: ready-for-agent

Completion: complete（2026-10-23）。验证见[知识库验证记录](../../../docs/verification-knowledge-base.md)。

## 依赖与范围

依赖 [01 独立存储](01-storage.md)、[02 文档入库](02-ingestion.md) 和 [03 对话工具](03-retrieval-tool.md)，完成[知识库规格](../spec.md)中的用户流程。

- 提供独立知识库入口、创建与重命名、文档上传列表、原件下载、删除和失败重试。
- 上传进度与后台阶段进度分别展示；图片和切片索引按真实计数更新，未知总量不伪造百分比。
- 显示图片部分失败、索引降级及阶段错误，刷新或重新进入后恢复实际状态。
- 会话可选择一个或多个本账号知识库，显示并保存选择；新会话默认不选择，取消选择不删除文档。
- 知识库删除后及时移除失效选择；附件上传入口保留独立语义。
- 完成文档上传、阶段观察、会话选择、按需召回和来源核对的端到端流程。

## 验收

通过浏览器覆盖含图片文档上传、后台进度、失败重试、刷新恢复、跨会话选择、取消选择和删除；核对每个可见进度和错误都有服务端事实支持。遵守所有新增或修改函数及回调的说明注释规范。
