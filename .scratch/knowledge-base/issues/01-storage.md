# 知识库独立存储与生命周期

Status: ready-for-agent

Completion: complete（2026-10-23）。验证见[知识库验证记录](../../../docs/verification-knowledge-base.md)。

## 范围

落实[知识库规格](../spec.md)的存储和权限边界：新增 `knowledge_bases`、`knowledge_documents`、`knowledge_chunks`、`knowledge_document_images`、`conversation_knowledge_bases`，以及持久处理任务状态。知识库原件与派生文件使用独立目录。

- 知识库归属于账号，文档归属于知识库，切片和图片归属于文档；会话选择必须同账号。
- 提供创建、重命名、列表、上传登记、下载和删除所需的数据访问接口与受保护 API。
- 不复用附件记录和切片表；附件到期清理与索引升级不得触碰知识库数据。
- 删除先撤销访问，再可重试清理数据、本机与远端文件；处理任务迟到写入不能恢复来源。
- 删除会话只清理选择关系；数据库升级保留现有附件及其索引。

## 验收

通过数据库迁移及公开 API 验证账号隔离、选择关系、删除中的并发处理、会话删除不删除知识库，以及附件和知识库使用独立表。遵守所有新增或修改函数的中文说明注释规范。
