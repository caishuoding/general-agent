# 05: 通过 Mem0 明确保存并查看记忆

**What to build:** 在聊天中明确说“记住”后直接保存，并在记忆管理页查看事实、来源和真实操作状态。

**Blocked by:** 04 — 用量展示与月度预算暂停。

**Status:** ready-for-agent

**Completion:** complete

**规格覆盖：** 个人对话智能体首版规格，用户故事 19、23、29、40、41。

- [x] 采用用户指定的 Mem0，在实现开始时锁定 SDK 版本并验证本机持久化方案；以 OSS 与 PostgreSQL/pgvector 为工程基线，不能静默改用托管记忆服务或其他正式数据库。
