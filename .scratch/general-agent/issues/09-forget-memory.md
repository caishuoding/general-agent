# 09: 删除记忆并防止旧来源自动恢复

**What to build:** 删除记忆后不再召回，也不会从同一旧来源自动重建；原聊天仍保留供用户回看。

**Blocked by:** 08 — 候选记忆与含义不明的变更确认。

**Status:** ready-for-agent

**Completion:** complete

**规格覆盖：** 个人对话智能体首版规格，用户故事 30、31、32、41。

- [x] 记忆管理页和明确删除请求可以删除指定条目，执行期间先停止召回，只有清理完成才报告成功。
- [x] 清理正式记忆、相关索引及应移除的 Mem0 内部历史正文；按锁定 SDK 验证实际行为，不能仅凭默认删除返回值认定已清除。
