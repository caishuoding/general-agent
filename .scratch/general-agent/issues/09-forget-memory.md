# 09: 删除记忆并防止旧来源自动恢复

**What to build:** 删除记忆后不再召回，也不会从同一旧来源自动重建；原聊天仍保留供用户回看。

**Blocked by:** 08 — 候选记忆与含义不明的变更确认。

**Status:** ready-for-agent

**规格覆盖：** 个人对话智能体首版规格，用户故事 30、31、32、41。

- [ ] 记忆管理页和明确删除请求可以删除指定条目，执行期间先停止召回，只有清理完成才报告成功。
- [ ] 清理正式记忆、相关索引及应移除的 Mem0 内部历史正文；按锁定 SDK 验证实际行为，不能仅凭默认删除返回值认定已清除。
- [ ] 保留防止从同一旧来源自动恢复所需的最小标记，标记不保存被删事实正文；旧候选的再次确认也不能绕过删除决定。
- [ ] 删除记忆保留原聊天；原聊天仍可主动回看，界面准确区分忘记记忆与删除原文。
- [ ] 部分失败、重启和重试不使已删除或正在删除的事实恢复为有效记忆；重复删除不导致误删其他条目。
- [ ] 真实 PostgreSQL 和 Mem0 集成及必要契约测试覆盖删除、历史清理、重新召回、旧来源提取、重启与恢复。
- [ ] 本任务涉及的启动、配置、数据位置和能力边界说明与实现同步更新。
- [ ] 所有新增或修改的函数、方法、构造函数、箭头函数和回调函数都有中文用途说明注释，逻辑改变时同步更新注释。
- [ ] 分别记录受控替身测试和真实服务验收结果；缺少凭据或尚未执行的真实请求明确标为待验，不以替身测试通过冒充真实服务兼容。
