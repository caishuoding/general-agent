# 16: 按明确要求检索旧聊天

**What to build:** 明确要求时查找其他会话的旧消息，打开原会话或消息出处；普通聊天不自动搜索。

**Blocked by:** 08 — 候选记忆与含义不明的变更确认；10 — 会话内上传文本并带出处回答。

**Status:** ready-for-agent

**Completion:** complete

**规格覆盖：** 个人对话智能体首版规格，用户故事 62、63、64、65、66。

- [x] 历史聊天检索仅由用户当前明确要求触发，通过独立的历史消息检索边界查找已保存的消息。
- [x] 结果提供原会话与消息出处，用户能回到原始讨论核对；来源不可用时准确说明。
- [x] 普通聊天不自动检索其他会话；检索结果不授权读取旧会话附件原文。
- [x] 检索到的旧消息不因进入上下文自动变成候选或正式记忆，也不能绕过已删除记忆的来源规则。
- [x] 索引与记忆集合保持独立，只返回仍存在且有效的消息，来源失效时不继续暴露残留索引正文；涉及嵌入和模型调用时遵守预算。
- [x] 真实 PostgreSQL 的应用接口测试覆盖显式触发、普通聊天不触发、出处、附件边界及候选提取隔离；存在 Mem0 行为时使用真实 Mem0。
- [x] 本任务涉及的启动、配置、数据位置和能力边界说明与实现同步更新。
- [x] 所有新增或修改的函数、方法、构造函数、箭头函数和回调函数都有中文用途说明注释，逻辑改变时同步更新注释。
- [x] 分别记录受控替身测试和真实服务验收结果；缺少凭据或尚未执行的真实请求明确标为待验，不以替身测试通过冒充真实服务兼容。
