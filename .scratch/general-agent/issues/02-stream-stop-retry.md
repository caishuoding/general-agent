# 02: 流式回答、停止与失败重试

**What to build:** 回答逐步显示，用户可以停止生成或重试失败的请求，消息和调用状态始终真实。

**Blocked by:** 01 — 本机启动与首次持久化对话。

**Status:** ready-for-agent

**规格覆盖：** 个人对话智能体首版规格，用户故事 12、13、14、83。

- [ ] 浏览器逐步显示生成中的回答，生成、完成、停止和失败状态在界面与持久化记录中一致。
- [ ] 停止操作阻止该次执行继续发起后续请求；已发出的请求若返回用量仍予记录，不宣称停止一定撤销服务商费用。
- [ ] 请求失败或流中断有明确提示与重试入口，保留已得到的部分内容及状态，不把不完整回答标为完成。
- [ ] 重试生成新的实际调用记录，避免意外重复用户消息；每次外部调用的费用信息分别记录。
- [ ] 通过应用接口和少量浏览器测试验证逐步展示、停止、断流、重试及重新进入会话后的状态；外部响应由受控替身提供。
- [ ] 本任务涉及的启动、配置、数据位置和能力边界说明与实现同步更新。
- [ ] 所有新增或修改的函数、方法、构造函数、箭头函数和回调函数都有中文用途说明注释，逻辑改变时同步更新注释。
- [ ] 分别记录受控替身测试和真实服务验收结果；缺少凭据或尚未执行的真实请求明确标为待验，不以替身测试通过冒充真实服务兼容。
