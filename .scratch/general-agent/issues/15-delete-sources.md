# 15: 删除会话或附件并处理关联记忆

**What to build:** 删除会话或文件前查看关联记忆，默认一起删除，也可保留指定记忆并标注来源已删除。

**Blocked by:** 09 — 删除记忆并防止旧来源自动恢复；14 — 从附件提取记忆并确认归属。

**Status:** ready-for-agent

**规格覆盖：** 个人对话智能体首版规格，用户故事 16、33、34、35、36、49、61。

- [ ] 删除会话或单个附件前展示所有受影响的关联记忆，默认勾选删除，允许用户明确保留部分条目。
- [ ] 删除会话移除其消息与附件；删除附件清理本机原文件、解析内容和派生检索记录，后续检索无法继续引用已移除来源。
- [ ] 保留的记忆继续可用并显示来源已删除；删除的记忆复用既有停止召回、历史清理与防自动恢复规则。
- [ ] 独立上传到其他会话的同名或同内容文件不受影响；其他来源和未选择删除的记忆不被误删。
- [ ] 部分失败、刷新、重启及重复请求有真实可恢复状态，不能在文件、索引或关联记忆尚未处理时虚报全部完成。
- [ ] 真实 PostgreSQL 和 Mem0 的应用接口测试覆盖两类来源删除、默认与保留选择、跨会话独立性、派生内容清理及失败恢复；浏览器测试验证影响预览。
- [ ] 本任务涉及的启动、配置、数据位置和能力边界说明与实现同步更新。
- [ ] 所有新增或修改的函数、方法、构造函数、箭头函数和回调函数都有中文用途说明注释，逻辑改变时同步更新注释。
- [ ] 分别记录受控替身测试和真实服务验收结果；缺少凭据或尚未执行的真实请求明确标为待验，不以替身测试通过冒充真实服务兼容。
