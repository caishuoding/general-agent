# 12: 图片上传与视觉问答

**What to build:** 上传 PNG 或 JPEG 并提问；使用已验证的图片模型，并指出回答依据的图片。

**Blocked by:** 10 — 会话内上传文本并带出处回答。

**Status:** ready-for-agent

**Completion:** complete

**规格覆盖：** 个人对话智能体首版规格，用户故事 45、50、51、55、57、60。

- [x] PNG 与 JPEG 通过会话附件流程上传、持久化并提交给已验证具备图片能力的模型，遵守数量和大小限制。
- [x] 图片只供所属会话使用，用户可对单独上传的图表或文档截图提问；返回内容引用对应图片，不编造不存在的页码或段落。
- [x] 图片能力缺失、图片损坏或服务拒绝时显示真实错误，不静默假装已看过图片。
- [x] 视觉请求遵守同一用量与预算规则，暂停、失败和重试的状态与附件及会话执行保持一致。
- [x] 通过应用接口及少量浏览器上传验证支持格式、会话隔离、能力不足与引用；实际视觉理解能力以真实服务验收结果为准。
- [x] 本任务涉及的启动、配置、数据位置和能力边界说明与实现同步更新。
- [x] 所有新增或修改的函数、方法、构造函数、箭头函数和回调函数都有中文用途说明注释，逻辑改变时同步更新注释。
- [x] 分别记录受控替身测试和真实服务验收结果；缺少凭据或尚未执行的真实请求明确标为待验，不以替身测试通过冒充真实服务兼容。
