# 17: 明确联网搜索与个人信息发送确认

**What to build:** 配置 Tavily 后按明确要求联网，回答附来源；发送记忆或附件中的个人信息前展示具体内容并确认。

**Blocked by:** 06 — 在新会话使用相关长期记忆；10 — 会话内上传文本并带出处回答。

**Status:** ready-for-agent

**规格覆盖：** 个人对话智能体首版规格，用户故事 6、7、67、68、69、70、71、72。

- [ ] 搜索服务独立配置与管理，未配置时提供设置提示且不阻碍聊天、附件或记忆；凭据遵守后端管理与掩码规则。
- [ ] 只有用户明确要求联网时调用 Tavily，回答提供可打开的来源链接，搜索失败或未执行不能说成已经查证。
- [ ] 拟发送记忆或附件中的个人信息时，先显示将发送的具体内容及用途，用户批准前不向搜索服务发送。
- [ ] 拒绝后不发送被拒内容；修改查询、重复提交、过期批准及其他会话的批准不能绕过当前具体内容的确认。
- [ ] 搜索、查询生成及后续模型调用统一计量，遵守预算暂停、恢复和重试规则。
- [ ] 应用接口测试用受控搜索与模型替身验证显式触发、未配置、失败、来源以及记忆和附件信息批准前后的实际发送内容；少量浏览器测试验证确认卡片。
- [ ] 本任务涉及的启动、配置、数据位置和能力边界说明与实现同步更新。
- [ ] 所有新增或修改的函数、方法、构造函数、箭头函数和回调函数都有中文用途说明注释，逻辑改变时同步更新注释。
- [ ] 分别记录受控替身测试和真实服务验收结果；缺少凭据或尚未执行的真实请求明确标为待验，不以替身测试通过冒充真实服务兼容。
