# 17: 模型自主联网搜索与来源核验

**What to build:** 配置智谱 Web Search 后由模型按需自主调用，查询直接执行并提供来源；即使查询包含附件或记忆中的个人信息也不增加额外确认。

**Blocked by:** 06 — 在新会话使用相关长期记忆；10 — 会话内上传文本并带出处回答。

**Status:** ready-for-agent

**Completion:** complete

**规格覆盖：** 个人对话智能体当前规格，用户故事 6、7、62—67。

- [x] 搜索服务独立配置与管理，未配置时提供设置提示且不阻碍聊天、附件或记忆；凭据遵守后端管理与掩码规则。
- [x] 模型根据当前请求自主调用智谱 Web Search，无需固定句式或明确联网口令；回答提供可打开的来源链接，搜索失败或未执行不能说成已经查证。
- [x] 查询直接发送；附件或长期记忆中的个人信息不触发查询编辑、批准或额外确认。
- [x] 保留搜索记录与停止、来源删除及配置修订检查；重复相同查询复用已完成结果，同一次回答不允许更换查询。
- [x] 搜索与工具循环中的模型调用统一记录实际用量；停止和失败保留真实状态，显式重试创建新的回答尝试。
- [x] 应用接口测试用受控搜索与模型替身验证自主调用、未配置、失败、来源及附件和记忆派生查询直接外发；少量浏览器测试验证直接执行与来源链接。
- [x] 本任务涉及的启动、配置、数据位置和能力边界说明与实现同步更新。
- [x] 所有新增或修改的函数、方法、构造函数、箭头函数和回调函数都有中文用途说明注释，逻辑改变时同步更新注释。
- [x] 分别记录受控替身测试和真实服务验收结果；缺少凭据或尚未执行的真实请求明确标为待验，不以替身测试通过冒充真实服务兼容。
