# 08: 候选记忆与含义不明的变更确认

**What to build:** 助手发现可能值得记住的信息时展示确认卡片；同意后生效，拒绝后不保存。

**Blocked by:** 07 — 修改记忆与明确更正。

**Status:** ready-for-agent

**Completion:** complete

**规格覆盖：** 个人对话智能体首版规格，用户故事 20、21、22、26、41。

- [x] 自动发现的新事实及“最近在杭州”等含义不明确的变化先成为候选，保存在应用业务状态中，确认前不写入正式 Mem0 记忆。
- [x] 卡片展示准备新增或变更的具体内容、来源和目标条目，用户可确认或拒绝；确认后复用已有正式保存或更新行为。
- [x] 拒绝后候选不生效；重复点击、刷新、过期候选及原条目已被更新的情形不会悄悄覆盖新事实。
- [x] 仅处理获准的当前聊天来源；模型回答、查回的旧消息或附件内容不因进入上下文而自动升级为候选或正式记忆。
- [x] 候选提取、确认后的保存和修改请求均遵守预算，提取或提交失败可见且不显示虚假成功。
- [x] 应用接口测试使用真实 PostgreSQL 和 Mem0，少量浏览器测试验证卡片、确认、拒绝、刷新及确认前后的跨会话行为。
- [x] 本任务涉及的启动、配置、数据位置和能力边界说明与实现同步更新。
- [x] 所有新增或修改的函数、方法、构造函数、箭头函数和回调函数都有中文用途说明注释，逻辑改变时同步更新注释。
- [x] 分别记录受控替身测试和真实服务验收结果；缺少凭据或尚未执行的真实请求明确标为待验，不以替身测试通过冒充真实服务兼容。
