# 06: 在新会话使用相关长期记忆

**What to build:** 新建会话后，回答自动使用相关的已保存记忆，同时保持附件和历史聊天的独立边界。

**Blocked by:** 05 — 通过 Mem0 明确保存并查看记忆。

**Status:** ready-for-agent

**Completion:** complete

**规格覆盖：** 个人对话智能体首版规格，用户故事 27、28、41。

- [x] 记忆以个人身份范围检索，可以跨会话生效，且只有相关、已批准、当前有效的条目参与回答。
- [x] 不因普通聊天自动读取其他会话消息或附件，记忆召回本身也不把上下文重新当成待保存的事实。
- [x] 召回产生的嵌入或模型请求受预算限制并计量；召回失败或被暂停时准确说明，不假装已取得记忆。
- [x] 通过应用接口，在多个会话及重启之后验证相关记忆生效、无关记忆不强行加入回答、未批准内容不可召回；使用真实 Mem0 和 PostgreSQL。
- [x] 本任务涉及的启动、配置、数据位置和能力边界说明与实现同步更新。
- [x] 所有新增或修改的函数、方法、构造函数、箭头函数和回调函数都有中文用途说明注释，逻辑改变时同步更新注释。
- [x] 分别记录受控替身测试和真实服务验收结果；缺少凭据或尚未执行的真实请求明确标为待验，不以替身测试通过冒充真实服务兼容。
