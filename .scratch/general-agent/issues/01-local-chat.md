# 01: 本机启动与首次持久化对话

**What to build:** 按启动说明打开本机 Web 应用，配置模型，创建或切换会话并完成文字对话；重启后仍能继续。

**Blocked by:** None (can start immediately)。

**Status:** ready-for-agent

**规格覆盖：** 个人对话智能体首版规格，用户故事 1、2、3、8、9、10、11、15、17、18。

- [ ] React 与 TypeScript 界面、FastAPI 后端及 Docker Compose PostgreSQL 形成可运行的最小完整流程；应用与数据库仅向本机开放，数据库使用持久化存储。
- [ ] 设置页可保存模型地址、密钥和模型名，后端管理凭据，读取配置只返回配置状态或掩码，日志不泄露密钥；配置失败可见且可修正。
- [ ] 会话列表、聊天主区域、记忆与设置入口可用；用户可新建、切换、发送文字并获得真实模型响应，尚未实现的能力不显示虚假的可用状态。
- [ ] 消息与所属会话持久化到 PostgreSQL，重新启动应用和数据库后可继续原会话；模型切换不删除历史记录。
- [ ] 外部请求使用可替换的调用边界，能够保存服务返回的用量与未知状态，供后续预算规则接入；失败不得伪造回答或成功状态。
- [ ] 应用对外接口测试使用真实 PostgreSQL 与可控模型替身验证会话隔离、持久化和失败；启动说明包含配置方式、依赖、数据位置及实际验证结果。
- [ ] 本任务涉及的启动、配置、数据位置和能力边界说明与实现同步更新。
- [ ] 所有新增或修改的函数、方法、构造函数、箭头函数和回调函数都有中文用途说明注释，逻辑改变时同步更新注释。
- [ ] 分别记录受控替身测试和真实服务验收结果；缺少凭据或尚未执行的真实请求明确标为待验，不以替身测试通过冒充真实服务兼容。
