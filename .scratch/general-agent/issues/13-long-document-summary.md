# 13: 长资料总结与多文件比较

**What to build:** 对长文档提出具体问题、要求全文总结或比较同一会话中的多份资料，且能核对覆盖范围和出处。

**Blocked by:** 11 — 文本 PDF 与 DOCX 阅读。

**Status:** ready-for-agent

**Completion:** complete

**规格覆盖：** 个人对话智能体首版规格，用户故事 54、56、57、58、59。

- [x] 具体问答从当前会话资料中取得相关内容并附引用，长资料索引独立于长期记忆。
- [x] 全文总结覆盖整份可处理资料，可分段处理后汇总；不能用少量检索片段冒充全文。
- [x] 比较同一会话内的多份资料时，分别标明各结论的来源；未读完或某份处理失败时明确说明覆盖缺口。
- [x] 处理过程中有进度或状态；预算暂停、停止和失败保留真实状态，恢复或重试不会把部分结果标为完整。
- [x] 所有分段、嵌入、总结及重试请求均被计量和预算控制，不因内部批量调用绕过限制。
- [x] 应用接口测试覆盖超出单次模型上下文的文档、末尾重要内容、多文件对比、错误出处、处理中断与预算暂停，外部模型返回由受控替身决定。
- [x] 本任务涉及的启动、配置、数据位置和能力边界说明与实现同步更新。
- [x] 所有新增或修改的函数、方法、构造函数、箭头函数和回调函数都有中文用途说明注释，逻辑改变时同步更新注释。
- [x] 分别记录受控替身测试和真实服务验收结果；缺少凭据或尚未执行的真实请求明确标为待验，不以替身测试通过冒充真实服务兼容。
