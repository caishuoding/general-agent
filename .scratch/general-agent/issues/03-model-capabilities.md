# 03: 模型能力验证与独立嵌入配置

**What to build:** 在设置页分别验证文字、图片、工具调用和嵌入能力，清楚知道当前服务能做什么。

**Blocked by:** 01 — 本机启动与首次持久化对话。

**Status:** ready-for-agent

**规格覆盖：** 个人对话智能体首版规格，用户故事 4、5、17。

- [ ] 设置分别保存聊天与嵌入服务的地址、模型名及凭据，允许服务支持时复用连接信息，但不假定聊天模型提供嵌入接口。
- [ ] 文字、图片、工具调用和嵌入检查分别展示结果与可解释的错误，部分能力失败不会被描述为全部成功。
- [ ] 验证请求通过已有外部调用边界并记录可获取的用量；测试按钮本身也属于可能产生费用的请求。
- [ ] 嵌入结果的模型标识、维度与连通性经过验证；存在检索索引后更换嵌入模型或维度时，先明确提示需要重建，重建能力交由任务 18 实现，禁止静默混用。
- [ ] 服务配置可修改且不会删除会话；完整密钥不出现在读取配置的响应或日志中。
- [ ] 使用可控服务响应从应用对外接口验证成功、能力缺失、认证失败、错误维度及配置持久化；真实服务支持情况只按实际结果标记。
- [ ] 本任务涉及的启动、配置、数据位置和能力边界说明与实现同步更新。
- [ ] 所有新增或修改的函数、方法、构造函数、箭头函数和回调函数都有中文用途说明注释，逻辑改变时同步更新注释。
- [ ] 分别记录受控替身测试和真实服务验收结果；缺少凭据或尚未执行的真实请求明确标为待验，不以替身测试通过冒充真实服务兼容。
