# 04: 用量展示与月度预算暂停

**What to build:** 查看本应用的用量和估算费用；达到预算或费用未知时暂停新请求，允许用户决定本次是否继续。

**Blocked by:** 02 — 流式回答、停止与失败重试；03 — 模型能力验证与独立嵌入配置。

**Status:** ready-for-agent

**Completion:** complete（2026-10-15）。Status 保留项目约定的分流标签；完成情况由本字段与验收清单记录。

**规格覆盖：** 个人对话智能体首版规格，用户故事 73、74、75、76、77、78、79、80、81、82、83、84。

- [x] 设置页可管理可选月度预算及调用所需单价，按本应用用量展示估算费用，并明确区分服务商实际账单。
- [x] 所有已经接入的聊天、能力检查与嵌入请求经过统一调用前检查和调用后计量；后续功能复用同一约束，不能从内部 SDK 或重试绕过。
- [x] 达到预算后阻止新的云端调用；启用预算且缺少单价时在调用前暂停，返回用量缺失时记录费用未知并暂停后续调用。
- [x] 暂停提示说明原因，支持补齐配置或明确允许本次继续；批准作用范围明确且不会变成对未来请求的永久豁免。
- [x] 未设置预算时允许正常使用并展示可取得的信息，缺失的用量和费用始终显示为未知，不能按零计。
- [x] 流式中止、能力检查、多轮工具请求、失败重试及并发请求不会重复记账或漏过已知的暂停状态；用户一次执行中的批准范围受后端校验。
- [x] 用真实 PostgreSQL 和可控外部响应，通过应用接口验证预算阈值、费用未知、当月统计、暂停恢复、重复提交与停止后的用量；少量浏览器测试覆盖预算提示。
- [x] 本任务涉及的启动、配置、数据位置和能力边界说明与实现同步更新。
- [x] 所有新增或修改的函数、方法、构造函数、箭头函数和回调函数都有中文用途说明注释，逻辑改变时同步更新注释。
- [x] 分别记录受控替身测试和真实服务验收结果；缺少凭据或尚未执行的真实请求明确标为待验，不以替身测试通过冒充真实服务兼容。
