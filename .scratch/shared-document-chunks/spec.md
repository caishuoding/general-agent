# 阅读工具复用检索切片并清理冗余存储

## 用户确认的行为

- 用户按文档 ID 和页码范围调用阅读工具，无需提供切片编号；TXT／Markdown 按段落范围定位。
- 根据已有检索切片的页码／段落元数据定位全部匹配片，按原文顺序返回完整切片。
- 允许切片跨页、内容超出请求范围，不裁剪、不额外解释，也不要求阅读结果暴露真实起止页码。
- 搜索与阅读只保留一份持久切片正文，删除冗余代码、多余数据库表和重复全文字段。
- 保留现有账号／会话隔离、到期／删除限制、每个工具每回答五次及阅读上下文预算限制。
- 超过预算按整片续读，游标由工具返回；首片无法放入时明确返回预算不足。
- 旧数据迁移不改变切片正文、向量及附件有效期。

## 验收接口

- 上传接口与文档工具：跨页完整片、页码与段落定位、原文顺序、匹配片不受搜索片数限制、整片续读、空白页、访问限制。
- 数据库迁移：通过旧版结构升级后调用阅读／搜索工具，确认切片可独立使用；确认冗余表列已删除，原件、向量和有效期保留。

决策及返回合同见 docs/adr/0014-shared-document-chunks.md。
